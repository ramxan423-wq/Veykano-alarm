# Mission Alarm Veykano

Android alarm and wake-up challenge app.

The Android Studio v1.12 source archive is stored in the repository as `Mission_Alarm_Veykano_v1.12_Dil_Taramasi_Kaynak.zip`. The `.github/workflows/build-apk.yml` workflow extracts the source and builds a debug APK via GitHub Actions.

Note: Language picker has 139 options but localization translations for all languages are not yet complete. This is an unsigned-for-release debug build, not a production release.
